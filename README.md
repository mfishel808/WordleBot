## WordleBot
This repository uses R programing to take in the .txt files below specifically "all possible words.txt" and "wordle-answers-alphabetical.txt" and uses them to guess the daily wordle with your feedback.

## How to use

To use the code download the repository and point Wordlebot2 to the appropriate files as shown in the example code. Then you just run the code and enter in the correct feedback for it to guess the next word. 
b=black(letter isn't in the word)
y=yellow(letter is in the word but in a different spot)
g=green(letter is in the word and in the correct spot)
